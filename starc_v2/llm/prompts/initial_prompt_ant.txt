Background – STARC distance (Standardized Reward Comparison)
• STARC compares two reward functions after removing harmless transformations (positive scaling and potential shaping) and after rescaling them to the same length.
• Internally it:
   1. uses a quick value‑function estimate to strip shaping,
   2. normalizes each reward,
   3. evaluates both on a fixed batch of 96 sampled transitions,
   4. returns the Euclidean distance between those 96‑D vectors.
• The score lies in [0, ∞). 0 = identical incentives (would yield the same optimal policy). Larger numbers mean genuinely different behavioural (policy) incentives.

All your rewards should accomplish the same goal, but you are allowed to use different logics to achieve it.
The goal is to balance the difference in logic and how better the reward may perform.
You will be called for 3 iterations. After evaluating the STARC matrix, decide whether you want to explore with more features or improve the existing features.
The reward should be presented as the sum of the features you use. The features should be positive but their weights can be negative.

```python
from typing import Optional
import numpy as np
import torch
from starc.core.reward_func import RewardFunc

class ExpertReward(RewardFunc):
    """
        A standard Ant locomotion reward: forward progress minus control cost.
    """
    def __call__(self,
                 env,  # Gym Ant env (unused in formula)
                 state: Optional[torch.Tensor],
                 action,
                 next_state,
                 x_velocity: float = None) -> float:
        # Proxy Ant reward:
        # reward = forward_reward - ctrl_cost
        forward_reward = 1.0 * (x_velocity or 0.0)
        ctrl_cost = 0.001 * np.sum(np.square(action))
        reward = forward_reward - ctrl_cost

        if hasattr(reward, 'item'): return reward.item()
        return reward
```
