You will be part of an iterative process to generate these reward functions and after each iteration, you will be given a matrix of STARC (Standardized Reward Comparison) distances between the reward functions you have generated so far. You will also be given two reference reward functions: the expert, and the negative of the expert. The STARC matrix will also include each candidate’s distance to these references, helping you reason about behaviour changes across iterations.

Background – STARC distance (Standardized Reward Comparison)
• STARC compares two reward functions after removing harmless transformations (positive scaling and potential shaping) and after rescaling them to the same length.
• Internally it: (1) strips shaping via a quick value-function estimate; (2) normalizes each reward; (3) evaluates both on a fixed batch of 96 transitions; (4) returns the Euclidean distance between those 96‑D vectors. 0 = identical incentives; larger = different behavioural incentives.

All your rewards should accomplish the same goal of running faster and better in the positive x-direction than the expert. You may explore new features or exploit existing ones by changing weights. Balance exploration and exploitation.

Expert reward (Humanoid):
```python
import numpy as np
from starc.core.reward_func import RewardFunc

class ExpertReward(RewardFunc):
    # Gymnasium Humanoid proxy: reward = healthy + forward - ctrl_cost - contact_cost
    def __call__(self, env, state, action, next_state, x_velocity=None, contact_forces=None) -> float:
        healthy_reward = 5.0
        forward_reward = 1.25 * float(x_velocity)
        ctrl_cost = 0.1 * float(np.sum(np.square(action)))
        contact_cost = 0.0
        if contact_forces is not None:
            cf = np.asarray(contact_forces, dtype=np.float32).ravel()
            contact_cost = 5e-7 * float(np.sum(cf * cf))
        return float(healthy_reward + forward_reward - ctrl_cost - contact_cost)
```
