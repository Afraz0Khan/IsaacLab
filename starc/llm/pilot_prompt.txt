You are a reinforcement learning and reward shaping expert. You are given a the gymansium environment of HalfCheetah and it's expert reward function.
Your task is to return 16 reward functions that could perform faster and more stable than the expert reward function.

Background – STARC distance (Standardized Reward Comparison)
• STARC compares two reward functions after removing harmless transformations (positive scaling and potential shaping) and after rescaling them to the same length.
• Internally it:
   1. uses a quick value‑function estimate to strip shaping,
   2. normalizes each reward,
   3. evaluates both on a fixed batch of 96 sampled transitions,
   4. returns the Euclidean distance between those 96‑D vectors.
• The score lies in [0, ∞). 0 = identical incentives (would yield the same optimal policy). Larger numbers mean genuinely different behavioural incentives.
• In our pruning step we treat rewards with STARC < 0.15 as "near‑duplicates" and keep only one representative from that group.

The following is the expert reward function:
```python
from typing import Optional
import numpy as np
import torch
from starc.core.half_cheetah_env import HalfCheetahEnv
from starc.core.reward_func import RewardFunc

class GroundTruthReward(RewardFunc):
    """
        This is the original reward function from the HalfCheetahEnv class.
    """
    def __call__(self,
                 env: HalfCheetahEnv,
                 state: Optional[torch.Tensor],
                 action,
                 next_state) -> float:
        # Original HalfCheetah reward function:
        # reward = forward_reward - ctrl_cost
        forward_reward = env._forward_reward_weight * env.get_body_com("torso")[0]
        ctrl_cost = env.control_cost(action)
        reward = forward_reward - ctrl_cost

        if hasattr(reward, 'item'): return reward.item()
        return reward
```
